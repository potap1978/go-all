# Дизайн-система Kaskad · серия go (панель и мастер «Быстрый старт»)

С версии 3.3.0. Источник — Claude Design, принят владельцем: `k3/design/quick-start-design-v2/`
(`handoff/HANDOFF.md`: §12 «Карточки в сетке», §13 «Вид»; `handoff/tokens.css` — палитра). До 3.3.0 — v1.
Здесь — как это устроено в коде и как пользоваться. Прототипы `.dc.html` — только для показа.

## Файлы (`lib/kaskad/panel/static/`)

| Файл | Что внутри | Кто подключает |
|---|---|---|
| `fonts/*.woff2`, `fonts/OFL-*.txt` | Onest 400–700, Rubik 500–700, JetBrains Mono 400–600 — переменные, подмножество (кириллица, латиница, знаки панели), 89 КБ на все три. Откуда и как собраны — `fonts/SOURCES.md` | `tokens.css` |
| `tokens.css` | `@font-face`, токены (цвета тёмной и светлой темы, оттенки фона, отступы, радиусы, размеры текста, высоты), «Вид» (`data-*` на `<html>`), основа страницы, `:focus-visible`, `prefers-reduced-motion`, ключевые кадры | панель, мастер — первым |
| `components.css` | общие компоненты: кнопки, статусы, сообщения, таблица «подпись — значение», карточка и сетка, поля, сегменты, переключатели, выбор карточкой, плитки, списки, таблицы, QR, окна, шторки, тост, правила телефона | панель, мастер — вторым |
| `styles.css` | только своё у панели: оболочка (меню, шапки, вкладки телефона), «Вид», карточки протоколов, блоки `kk-*` | панель |
| `boot.js` | первый кадр (тема из `localStorage`) и `window.KaskadLook` — расчёт акцента | панель, мастер — в `<head>` до стилей |
| `user.css` | страница человека: те же токены, пересчитанные в sRGB, без шрифтов и запросов | только `user.html` |

Порядок в `index.html`: `boot.js` → `tokens.css` → `components.css` → `styles.css`. Мастер (`static/setup/*`)
подключает `boot.js`, `tokens.css`, `components.css` и свой `setup/*.css`. CSP — `style-src 'self'`: атрибута
`style` в разметке нет; переменные значения (ширина полосы, `--cols` таблицы) — только через CSSOM из JS.
Шрифты сервер отдаёт по `/fonts/<имя>.woff2` (рядом с `tokens.css`, работает и за секретным префиксом).

Включение: `<html data-hero data-theme="dark|light">` (+ `data-tint`, `data-density`, `data-btn`, `data-cards`,
`data-fs`, `data-vibrant`, `data-motion`, `data-device="phone|desktop"`).

## Токены (коротко)

- Поверхности: `--background`, `--surface`, `--surface-2`, `--surface-3`, `--field-background`, `--frame-bg`
  (рамка контента), граница `--border`, линия между строками `--separator`.
- Текст: `--foreground`, `--text-2` (подписи), `--text-3` (вторая строка, подсказки).
- Смыслы — не зависят от акцента: `--success|warning|danger` + `-soft` (фон) + `-text` (текст).
  Информация — нейтральная: `--info-soft` (= `--surface-2`), `--info-text` (= `--text-2`).
- Акцент — только действия, выбор и прогресс: `--accent`, `--accent-foreground` (текст на акценте),
  `--accent-text` (акцент текстом на поверхности), `--accent-soft`, `--accent-hover`, `--accent-press`.
- Отступы `--sp-1…--sp-12` (4…48), радиусы от `--radius`: `--r-tag 8`, `--r-field 12`, `--r-tile 16`,
  `--r-card 20`, `--r-dialog 24`, `--r-btn` (круглые / скруглённые — «Вид»).
- Шрифты: `--font` (Onest), `--font-head` (Rubik — заголовки экрана, карточки, окна), `--mono` (JetBrains Mono —
  IP, порты, ключи, команды, строчными). Капс моноширинным (`.gx-caption`) — только рельс и шапка шага мастера.
- Высоты: `--h-chip 24`, `--h-sm 32`, `--h-md 40`, `--h-field 44`, `--h-lg 48`. Таблица: `--kv-label 136px`.
- Плотность («Подробность» в «Виде»): `--page-p`, `--gap`, `--card-p`, `--card-gap`, `--row`. «Детально»
  (по умолчанию) — значения дизайн-системы: поля страницы 32, карточка 24, между блоками 20; телефон — 16 / 20.

## Акцент: `window.KaskadLook` (boot.js)

```js
KaskadLook.accents(theme, hue)   // цвета акцентов «Вида»: auto (по умолчанию: мятный #45D0C0 в тёмной, фиолетовый
                                 // oklch(.53 .17 288) в светлой — как мастер), ga (синий «Каскад» — готовая тема),
                                 // blue, sky, lavender, mint, coral, graphite, custom
KaskadLook.tones(accent, theme)  // { fg, text, near }: fg — белый или тёмный тон того же оттенка (контраст ≥ 4,5 : 1),
                                 // text — акцент для текста на поверхности (≥ 4,5 : 1), near — оттенок ближе 40° к красному
KaskadLook.apply(root, accent, theme)  // ставит --accent, --accent-foreground, --accent-text, data-accent-near
```

Мастер ставит свой акцент продукта тем же `apply` (Kaskad: `#45D0C0` в тёмной теме, `oklch(.53 .17 288)` в светлой).

| `ga-btn--tertiary` | второстепенная | `"tertiary"` |

| `ga-btn--danger` | опасная — только подтверждение в окне | `"danger"` |
| `ga-btn--inverse` | второстепенная внутри цветного сообщения | `"inverse"` |
| `ga-btn--sm / --icon / --full / --ml` | размеры; sm — в строках и плитках | `o.md`, `o.icon` без текста, `o.full`, `o.ml` |
| `ga-btn[aria-busy="true"]` | «идёт действие»: кольцо вместо значка | само: обработчик вернул обещание |
| `gx-chip--success / --warning / --danger` | статус: точка + слово | `U.chip(слово, тон)` |

| `gx-al--success / --warning / --danger / --plain` | сообщение; красный — только ошибка; `--card` — во всю ширину; `--row` — действие справа | `U.al(тон, жирное, текст, { btns, card, row })`; `"accent"` → `--plain` |
| `gx-kv` (`__row` = `display: contents`, `__k`, `__v`, `__text`, `__copy`, `__end`) | таблица одной сеткой; статус — колонкой; копирование — значком 28 px | `U.kv([{ k, v, s, mono, wrap, main, copy, chip }])` |
| `gx-card` (`__head`, `__ic`, `__actions`, `__danger`) | карточка: значок 40, заголовок Rubik 17, ряд действий, опасная зона | `U.sec(заголовок, описание, блоки, { icon, acts, actions, danger, list })` |
| `gx-cols > gx-col` | две независимые стопки карточек (без растяжения по высоте) | `U.cols([...], [...])` |
| `gx-list` (`__ic`, `__b`, `__st`, `__btns`) | список одной сеткой; статусы — своей колонкой | `U.list([{ title, meta, chips, tags, btns }])` |
| `gx-cards > gx-tc` | плитки (выходы, подписки): одной высоты, действия прижаты к низу; ряд — кнопки слева, значки справа (`icons`), корзина (`del: {name, warn, run}` или своя `trash`) | `U.cards([...])` |
| корзина и подтверждение на месте | значок 32 px с подписью («Удалить», aria «Удалить «имя»»); ряд действий меняется на «Удалить «имя»? Отмена · Удалить», `warn` — строкой над ним; Esc — назад | `U.trash(имя, onClick)`, `U.askDelete(ряд, {name, warn, run})` |
| `gx-menu-btn`, `gx-menu` (`__item`, `__item--danger`, `__sep`) | меню «⋯»: кнопка-значок 32 px «Ещё действия» и список `role=menu` слоем у неё; стрелки, Home/End, Esc, щелчок мимо, фокус — обратно на кнопку | `U.menu([{ label, icon, on, danger, sep }], { label })` |

Правила (HANDOFF §2а): ряд действий — от левого края подписей, слева направо по важности, кнопки не переносят текст;
главное значение карточки (`main`) — одно, 600; моноширинное значение — одной строкой с многоточием, целиком — в
подсказке и по «Скопировать» (`wrap` — для списков адресов, переносятся); номеров у карточек панели нет.

Действий в карточке больше, чем влезает в строку (карточки протоколов — от четырёх, `IB_MENU_FROM` в `app.js`): главное —
кнопкой слева, второстепенные — меню «⋯» рядом с ним, удаление — корзиной справа с подтверждением на месте, как у всех
протоколов. Сейчас меню у VLESS в режиме Reality (порт, сайт маскировки, новые ключи, режим); до трёх действий — строкой.

## Карточки в сетке и «Вид» (HANDOFF v2 §12–13)

- **Удаление** у выходов, протоколов и людей: корзина с подписью и подтверждением на
  месте. Что ещё случится — строкой предупреждения над подтверждением (последний ключ, маршруты, где выбран выход, ключ
  подписки станет исключённым; устройства на протоколе; устройства человека). Человек с устройствами — после
  подтверждения ещё ввод имени: устройства и ключи не вернуть. У подписки корзина открывает окно выбора «с ключами /
  оставить ключи».
- **«Подробность»** — три карточки с подписью (`role="radiogroup"`, стрелки — по кругу): набросок плотности, имя,
  что это значит. На телефоне — друг под другом. Предпросмотр меняет отступы карточки и число строк (минимализм —
  одна, баланс — две, детально — три и сообщение).

## Доступность

- `:focus-visible` — кольцо акцентным текстом у всех интерактивных элементов (`tokens.css`), у кнопок — `--focus-ring`.
- Кнопки-значки — с `aria-label` и `title` (`U.btn("", …, { tip })`, `U.copyIcon`); значки `aria-hidden`.
- `prefers-reduced-motion` и «Анимации: выкл.» в «Виде» выключают анимации и переходы.
- Цели касания на телефоне — не меньше 44 px, поля — шрифт 16 px (иначе iOS увеличивает страницу).
- Пока открыт слой (окно, лист, форма во весь экран), панель под ним `inert`: нижние вкладки телефона, видные над
  формой во весь экран (М10), притушены `--disabled-opacity` — видно, что сначала нужно закрыть форму.

## Отличия от выгрузки Claude Design (решения при переносе)

- **Палитра (3.3.0) — одна, v2** (`handoff/tokens.css` v2 = прототипы мастера и панели v2): тёмная — фон
  `oklch(.15 .012 255)`, поверхности `.205/.245/.29 .015 255`, граница `.31 .016 255`; светлая — нейтрали оттенка
  акцента Kaskad (`--neutral-hue: 288`); статусы v2 и `--danger-strong` (заливка опасной кнопки, текст белый). Палитра
  v1 (`oklch(.13 .005 286)`) убрана. Отличие от v2: `--text-3` светлой — `.52`, а не `.56` (контраст подсказок ≥ 4,5 : 1
  на белом), тёмной — `.64`. «Холодный» оттенок фона — 255 насыщеннее (тёмная) и как у goVLESS (светлая).
- **Акцент по умолчанию (решение владельца 3.3.0)** — как в мастере: мятный `#45D0C0` в тёмной теме, фиолетовый
  `oklch(.53 .17 288)` в светлой (`accent: "auto"`); текст на акценте — по контрасту (`KaskadLook.tones`). «Сбросить
  вид» возвращает к нему. Синий «Каскад» `oklch(.54 .13 222)` (не `.56` из прототипа: при `.56` белый текст даёт
  4,3 : 1) — готовая тема «Синий «Каскад»». Одноразовая миграция: «Вид», сохранённый до 3.3.0 с прежним синим по
  умолчанию, получает новое умолчание — на узле (`appearance.json` без `"v": 2`) и в браузере (`kaskad-appearance-v1`
  без `v: 2`); тема, подробность и другие акценты не меняются. Синий, выбранный после, сохраняется с `v: 2`. Коралловый `oklch(.68 .17 38)`, мятный `#45D0C0`, лаванда `oklch(.62 .17 290)` — как в макете.
  У лаванды по правилу контраста текст на акценте тёмный (в макете — белый, 3,6 : 1).
- **Шрифты** — переменные woff2 (по одному файлу на семейство) вместо десяти файлов по весам из `tokens.css`.
- **Плотность.** «Детально» (по умолчанию) — значения дизайн-системы; «Баланс» и «Минимализм» просторнее.
- **Карточки «Вида»:** «Тень» — граница + тень светлой темы (как в макете), «Рамка» — без тени, «Плоские» —
  поверхность `--surface-2` без границы.
- **Страница человека** (`user.css`) — те же токены в sRGB, без своих шрифтов (публичная страница не делает лишних
  запросов; тест `test_userpage_static_cli` запрещает `url()`): Onest/Rubik — если они есть в системе.
- **Схема** (`graph.css`) — только цвета и шрифты из токенов; подписи узлов без капса.
