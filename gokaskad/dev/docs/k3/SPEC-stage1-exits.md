# Kaskad 3 · этап 1 — выходы: здоровье, уровни, резерв по условиям, новые ключи (SPEC) — оглавление

С 16.10.2026 ТЗ разбито (D-113) на 19 частей в папке [`SPEC-stage1-exits/`](SPEC-stage1-exits/) — по 30–50 КБ, по смыслу.
Текст не менялся (кроме одной правки, ниже): части — подряд идущие куски прежнего файла (`dev-s1` = `1fcb9fb`, 690 КБ), склейка частей по
порядку равна ему байт в байт, если убрать пометки журнала решений « (D-NNN)» и учесть одну правку текста 16.10:
§2.9 `gateway.tg_proxy_group` → `exit_policy.tg_proxy_group` (D-133). Решения владельца и координатора —
[`DECISIONS.md`](DECISIONS.md): пометка «(D-NNN)» в тексте ведёт туда; в ТЗ она стоит в каждом разделе из столбца
«Где», поэтому поиск «D-NNN» находит все места решения в ТЗ; места вне ТЗ (план, `process/`, код) — в «Где».

**Как найти раздел.** Заголовки §N.M остались прежними, в своих частях: `grep -rn "^### 3.2 " docs/k3/SPEC-stage1-exits/`.

Ссылки со строкой «SE §7.1 (:2213)» в `k3/handoff/UX-FOUNDATION.md` даны по коммиту `cf99e68`: до строки 861
номер тот же, после — прибавить 4 (строки 3.1 «После `gw purge`…» добавлены в `1fcb9fb`); часть — та, в чей
диапазон «Строки» попадает номер; строка в части = номер − начало диапазона + 1.

**Правка ТЗ** — в своей части, по-прежнему одним коммитом с картой зависимостей. Часть выросла больше 60 КБ —
