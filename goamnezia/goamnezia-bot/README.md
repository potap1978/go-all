# goAmnezia pro — Telegram-бот

Второй интерфейс к тому же ядру, что SSH-меню `goamnezia`: всё, что есть в дереве
меню (PLAN.md §5.1), доступно из Telegram. Бот **ничего не пишет сам** — каждая
мутация идёт через мост `install.sh --action=<имя> --json --k=v` под общим замком
`/run/goamnezia/config.lock`, поэтому SSH, бот, панель и MCP-агенты не мешают друг
другу (docs/CONTRACT.md §0 п.3–4, §6).

## Что умеет

| Раздел | Экраны |
|---|---|
| Главный | дашборд: режим, адрес, домен, профили (`●` работает · `↻` перезапускается · `○` остановлен · `✗` нет контейнера · `⚠` Docker не отвечает), строка о расхождении режима и порта VPN, строка о почти полном диске (`status.disk.level` low — свободно меньше 1024 МБ, critical — меньше 512 МБ: сколько свободно и что сделать) с кнопкой «🩺 Диагностика», число пользователей; кнопки разделов, «Панель» (WebApp, если включён мини-апп), «Установить» (если `installed=false`), «Закрыть» |
| Пользователи | список страницами по 8 с пометками `● ○ ⏳ ▮`; мастер добавления (идентификатор → галочки профилей → лимит → срок; лимит — кнопки 10 / 50 / 100 / 200 ГБ, срок — 30 / 90 / 180 / 365 дней или своё число текстом, а **«Без лимита» и «Бессрочно» — отдельными кнопками** ниже, не цифрой 0: в SSH «0» значит «назад» (прежний «0» и слова кнопок, набранные текстом, бот понимает); на каждом шаге «Назад», экран с галочками пропускается, если профиль один — отдельного вопроса про отображаемое имя нет, идентификатор и есть имя; под вопросом об имени «🎲 Случайное имя» — вариант «прилагательное + столица» от ядра в том же сообщении, «✓ Взять» даёт и id, и подпись «Туманный Лондон», «🎲 Ещё» — другой вариант); карточка с блоком на каждый профиль и **ключами в двух стилях**: «QR .conf» и «.conf файлом» для клиента AmneziaWG, «Ключ Amnezia» (`vpn://` в `<code>`) и «QR Amnezia» (серия PNG по чанкам) для приложения; «Скачать файлом по ссылке» (временная раздача, см. ниже); у профиля, чей ключ выдан в приложении Amnezia до подхвата, вместо выдачи — объяснение и два выхода: «📎 Привязать старый ключ» (прислать ту ссылку `vpn://` или файл `.conf`, что человеку когда-то отправили; у него ничего не меняется) и «⚠️ Перевыпустить ключ»; Лимит · Срок (те же кнопки, «Без лимита» и «Бессрочно» — тоже) · Выключить/Включить · Переименовать · Добавить профиль · Убрать профиль · Удалить (фраза `DELETE <имя>`, 60 с) |
| Состояние | Статус · Трафик (в сети = выходил на связь за последние 3 мин; в карточке — «был в сети … назад») · Логи (кнопка на каждый компонент, который на сервере есть, с человеческим названием вместо кода) · Адреса |
| Протоколы | карточка профиля (состояние, порт, подсеть, линейка, версия ядра, ключей выдано; неустановленный — `◌`): Установить/Удалить (`REMOVE <профиль>`) · Порт · Занять UDP/443 · Подсеть (предупреждение + подтверждение) · MTU · Параметры (список; «Изменить» — выбор ключа кнопками, ввод значения, для серверных предупреждение о перевыпуске ключей) · Пресет · Перегенерировать (`REGEN <профиль>`) · Перезапуск · 🩹 Поднять контейнер заново (из копии состояния, ключи прежние) |
| Обслуживание | Перезапуск всего · Бэкап · Восстановить (список → `RESTORE <файл>`) · Обновления Amnezia · Импорт существующей Amnezia · Диагностика · Активные раздачи · Обновить goAmnezia (подсказка) |
| Настройки | Режим и сайт (смена режима с объяснением каждого и фразой `MODE <режим>` · шаблон сайта из каталога — категории, поиск, «наугад», фраза `TEMPLATE site` · проверка сайта · заголовок Alt-Svc · предполётная проверка портов 80/443) · DNS клиентов (Cloudflare/Google/AdGuard/свой) · Адрес сервера в ключах · Панель на домене (открыть, закрыть, сменить секретный путь) · Доступы агентов · Админы (список; добавлять — `/invite` — и удалять может только владелец) · Язык (свой в этом чате и общий для продукта) · О программе · Удалить всё (подсказка про SSH) |

Уведомления: раз в 30 с бот читает очередь `/run/goamnezia/notify/*.json` (её пишут
таймеры ядра) и шлёт админам: лимит и срок пользователя (заранее и по факту), контейнер
упал / поднят сторожем / пропал, демон Docker не отвечает, адрес сервера замолчал или снова
принимает, сменился IP сервера, сертификат истекает или не читается, бэкап не удался,
обновление Amnezia, события доступов агентов (первое использование, новый адрес, клон, срок,
частота); файл события удаляется. Полный список — docs/BOT.md §6.

Команды: `/start`, `/help`, `/users`, `/status`, `/adduser <имя> [ГБ] [дней]`,
`/key <имя> [профиль]` (профиль — линией, как на экранах: `/key anna 2.0`; прежний `awg2` тоже понимается), `/invite <id>`
(только владелец; остальным бот отвечает, что назначать администраторов может только владелец), `/lang`. Набор объявляется через
`set_my_commands` (RU по умолчанию, EN для клиентов с `language_code=en`).

Разрушительные действия закрыты typed-confirm: бот просит прислать фразу
(`DELETE anna`, `REMOVE awg3`, `REGEN awg2`, `RESTORE <файл>`, `MODE pro`,
`TEMPLATE site`) и ждёт её 60 секунд; любая кнопка отменяет. Мутации
сериализуются замком процесса и flock моста.

**Временная ссылка на файл** (`lib/share.sh`, docs/SHARE.md). В карточке
пользователя — «Скачать файлом по ссылке»: выбор профиля (если он не один) и
формата — файл `.conf` или ключ приложения файлом. QR по ссылке не отдаётся: он
и так есть кнопками рядом, там его удобнее сканировать. Адрес **равен ключу**,
поэтому приходит отдельным сообщением моноширинным текстом, без предпросмотра
ссылки, с предупреждением и сроком (5 минут); в лог бота уходит только `id`
раздачи. По истечении срока бот удаляет своё сообщение с адресом сам, снять
раздачу раньше можно кнопкой на нём же или в «Обслуживание → Активные раздачи».

Ни одна кнопка не молчит: неверные данные в `callback_data` показывают экран
«Некорректный ввод» с «Назад» или алерт — голый выход из обработчика в Telegram
выглядит как сломанный бот. Значки закреплены по одному на понятие: `⏸`
выключить, `▶️` включить, `🔄` обновить экран, `♻️` перезапустить контейнер,
`⚠️` перевыпустить или сгенерировать заново (старое перестаёт работать сразу), `🎲` наугад (случайное имя, порт, шаблон), `🔎` найти и проверить, `🗑` удалить, `➖` убрать,
`✅` подтвердить, `🔗` секретный адрес.

## Установка

Из SSH-меню (`goamnezia` → Telegram-бот → Установить) или руками:

```bash
sudo /opt/goamnezia/goamnezia-bot/install_bot.sh          # спросит токен и кто администратор (Enter — сообщением, без ID)
sudo /opt/goamnezia/goamnezia-bot/install_bot.sh --pair   # окно привязки администратора сообщением
sudo BOT_TOKEN=… ALLOWED_IDS=… /opt/goamnezia/goamnezia-bot/install_bot.sh --auto
sudo BOT_TOKEN=… ALLOWED_IDS= GOAMNEZIA_ADMIN_CLAIM=1 /opt/goamnezia/goamnezia-bot/install_bot.sh --auto
```

Установщик ставит `python3-venv`, создаёт `/opt/goamnezia-bot/venv`, копирует файлы,
пишет `.env` (0600) и юнит `goamnezia-bot.service` (root, `Restart=always`,
`RestartSec=5`, `EnvironmentFile=/opt/goamnezia-bot/.env`). Контракт установки —
[docs/BOT.md](../docs/BOT.md).

**Администратор — сообщением с подтверждением в SSH** (с 0.5.0), свой Telegram ID знать не нужно. Установщик
спрашивает «Кто будет администратором бота?»: `1` (Enter) — «Напишу боту и подтвержу здесь, в терминале», `2` —
ввести Telegram ID вручную (запасной путь). SSH открывает окно привязки (мастер
после установки бота, интерактивный установщик сразу после запуска бота, «Telegram-бот → Администраторы →
Привязать по сообщению» — всё это `install_bot.sh --pair`), человек пишет боту
любое сообщение, бот записывает его в кандидаты (первых десять) и отвечает тем же, что любому чужому
и вне окна, — «Это бот частного сервера. Если вы его владелец — откройте SSH-терминал сервера», — а SSH
показывает написавших: номер себя в списке → «Это вы? 1 — да, это я · 0 — отмена». Подтвердили — бот сам,
без перезапуска, подхватывает админа из `.env`, пишет «✓ Вы администратор сервера …» и показывает
меню. Имя бота может знать кто угодно, но SSH у постороннего нет — первый написавший админом не
станет. Тем же окном добавляют и следующих админов — без ID, по одному (прежние остаются); `/invite <id>` в боте —
только у владельца. Файлы и порядок — [docs/BOT.md](../docs/BOT.md) «Контракт привязки».

Запасной путь для установки без терминала — одноразовый код: установщик показывает восьмизначный код
и ссылку `t.me/<бот>?start=<код>`, кладёт код в `/opt/goamnezia-bot/.admin_claim_code` и рядом открывает
окно привязки на 10 минут (оба 0600) — срок назван временем. Бот принимает код только пока открыто это
окно; рестарт бота окна не открывает, код не переживает своё окно, а новый запуск установщика выдаёт
новый код с новым окном.

### Требования

- Python 3.8+ (проверено на 3.9 и 3.12), `python3-venv`
- Linux с systemd, установленный goAmnezia (`/opt/goamnezia/install.sh`)
- токен бота от @BotFather; **один токен — один сервер** (второй экземпляр получает 409)

### `.env`

| Переменная | Что |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ALLOWED_IDS` | Telegram ID админов через запятую. Пусто — **никого не пускать**: админа привязывают сообщением в окне, которое открывает SSH (запасной путь — одноразовый код из `.admin_claim_code`, тоже только в окне); бот перечитывает список сам, когда SSH подтвердит привязку |
| `OWNER_ID` | владелец — единственный, кто добавляет (`/invite`) и удаляет админов; пишет установщик (первый из введённых ID), SSH при привязке сообщением первого администратора или бот при назначении по коду; сменить — SSH «Telegram-бот → Администраторы → Назначить владельца» |
| `GOAMNEZIA_LANG` | запасной язык `ru`/`en`: действует, только пока в `config.json` goAmnezia нет `lang` (язык продукта главнее и меняется «для всех» из SSH, панели и бота); каждый админ может выбрать свой в «Настройки → Язык» (`user_langs.json`) |
| `GOAMNEZIA_ACTION_BIN` | путь к мосту, по умолчанию `/opt/goamnezia/install.sh` |
| `GOAMNEZIA_NOTIFY_DIR` | очередь уведомлений, по умолчанию `/run/goamnezia/notify` |
| `GOAMNEZIA_CATALOG` | каталог шаблонов сайта, по умолчанию `/opt/goamnezia/templates_catalog.json` (та же переменная, что у панели); файла нет — экран шаблонов честно скажет об этом |

## Безопасность

- `.env` 0600, каталог 0700; токен не попадает в логи (httpx на WARNING) и в argv: установщик
  отдаёт адрес Bot API curl конфигом из stdin (`curl -K -`).
- Только личный чат: команды, текст, файлы и кнопки из групп и каналов бот не слышит (фильтр PTB
  на входе и проверка в обработчиках). Незнакомцу — не больше трёх ответов в минуту, всем чужим —
  не больше тридцати, сверх — тишина; текст чужих сообщений в лог не пишется.
- Администратор — сообщением с подтверждением в SSH (см. «Установка»): окно открывает только root,
  имя и @username кандидатов чистятся до записи (их печатает терминал), кандидатов не больше десяти.
  Запасной одноразовый код — только в окне; пять неверных кодов от человека — дальше он без ответа;
  назначение под замком (два «Да» разом — один админ).
- Сообщение админа с ключом («Привязать старый ключ») бот убирает из чата на любом пути, даже когда
  до проверки дело не дошло.
- Всё, что уходит в мост, проверяется регексами из `lib/actions.json` до `subprocess`
  (имя `^[A-Za-z0-9_-]{1,32}$`, профиль по белому списку, порт, подсеть, хост, DNS).
- `html.escape` для всего динамического; приватный ключ показывается только по
  запросу ключа и не пишется в лог; QR — во временный каталог `mktemp` (0700),
  удаляется в `finally`.
- Бот работает от root (как goTelegram): мосту нужны docker и `/opt/goamnezia`.
  Демон по UNIX-сокету — этап упрочнения (PLAN.md §10).

## Устройство bot.py

Один файл, разделы по порядку: конфигурация и валидаторы → доступ (ALLOWED_IDS,
окно привязки, кандидаты, одноразовый код) → мост (`sh`, `parse_bridge_output`, `run_bot_action`) →
чистые помощники (значки, страницы, QR-файлы, `TypedConfirm`, очередь уведомлений) →
помощники Telegram (`safe_edit_message`, `_menu_rows`, кэш `status`, flow ввода) →
разделы (Пользователи, Состояние, Протоколы, Обслуживание, Настройки) → команды →
текстовый роутер → `EXACT_HANDLERS`/`PREFIX_HANDLERS` → уведомления → привязка (подтверждение из
SSH, `_pairing_loop`) → `main()`.

Соглашение callback_data (≤ 64 байт, разделитель `~`): `menu_*`, `sec_*` — разделы;
`u_*` — пользователи (`u_view~<name>`, `u_key~<name>~<profile>~<qrconf|conf|vpn|qrvpn>`,
`u_share~<name>` → `u_shf~<name>~<profile>` → `u_shdo~<name>~<profile>~<conf|vpn>`);
`ua_*` — мастер добавления; `sh_*` — раздачи; `st_*` — состояние; `pr_*` — протоколы
(`pr_card~<profile>`); `mt_*` — обслуживание; `se_*` — настройки (`se_mode_to~<режим>`,
`se_tplc~<категория>~<страница>`, `se_tplp~<короткий ключ шаблона>`, `se_mini~<on|off|rot>`,
`lang_prod_<код>`); `tc_cancel~<назад>` — отмена typed-confirm.

Шаблон сайта в callback_data не помещается (id до 120 символов), поэтому кнопка
несёт `sha1[:12]` от id, а карта ключ→id живёт в `context.user_data["tpl_keys"]`;
устаревший ключ (бот перезапустили) честно говорит об этом алертом. Сам каталог
(33 тысячи записей, 14 МБ) бот читает через `lib/catalog_tool.py` — лениво, в
отдельном потоке и с кэшем по mtime, как это делает панель.
