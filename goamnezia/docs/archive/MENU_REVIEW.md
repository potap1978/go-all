# Тест-ревью: обойти все экраны SSH-меню, бота и панели

Список составлен так, чтобы каждый прогон задевал все подсистемы — ключи,
контейнеры, конфиг, nginx, сертификаты, файрвол, бэкапы, панель, MCP, словари.

Условные обозначения:

| знак | значение |
|---|---|
| **[A]** | действие под экраном покрыто автоматическим прогоном — экран можно не кликать ради самой логики |
| **[Р]** | только руками: автопрогона нет |
| **[!]** | меняет состояние сервера |
| **[✗]** | **не запускать на боевом** — объяснено почему |

> Составлено под версию **0.1.0**, коммит `57579c5`. Важное отличие от
> goTelegram: **живого стенда не было ни разу**, поэтому пометка [A] здесь
> означает «покрыто прогоном без Docker», а не «проверено на сервере».
> Обхода SSH-меню и бота под pty у нас нет — экраны как таковые не кликал никто.
> План приёмки на настоящем сервере — [STAND.md](STAND.md).

## 0. Перед началом

```bash
BASH5=/opt/homebrew/bin/bash bash tests/run_static.sh
```

Ожидаемо: всё зелёное, юнит-тестов 283 (8 пропущено), сквозных проверок
135 + 315 + 116 + 92 + 62 + 63 + 39 + 90 = 912.

Снять исходное состояние, чтобы вернуть:

```bash
cp /opt/goamnezia/config.json /root/config.before.json
cp /opt/goamnezia/users.json  /root/users.before.json
docker ps --format '{{.Names}} {{.Status}} {{.Ports}}' | tee /root/docker.before
systemctl is-active docker nginx goamnezia-bot goamnezia-admin
goamnezia --action=status --json | tee /root/status.before.json
```

## 9. После прогона

```bash
diff <(jq -S . /root/config.before.json) <(jq -S . /opt/goamnezia/config.json)
diff <(jq -S . /root/users.before.json)  <(jq -S . /opt/goamnezia/users.json)
docker ps --format '{{.Names}} {{.Status}} {{.Ports}}' | diff /root/docker.before -
systemctl is-active docker nginx goamnezia-bot goamnezia-admin goamnezia-mcp-http
systemctl list-timers 'goamnezia-*' --no-pager
journalctl -u goamnezia-bot -u goamnezia-admin -u nginx --since "-2h" -p err --no-pager
grep -c zz_ /opt/goamnezia/users.json          # тестовых пользователей не осталось
grep -rn 'a-[A-Za-z0-9_-]\{40,\}' /var/log/nginx/access.log /var/log/goamnezia-audit.log
```

Последняя строка — самая важная: секретов доступа агентов **не должно быть**
ни в одном логе.

## Чего этот обход НЕ покрывает

- **работает ли VPN на самом деле** — проверяется только живым клиентом на
  живом канале;
- поведение при потере сети посреди действия (особенно посреди пересоздания
  контейнера);
- одновременная работа двух администраторов из разных интерфейсов;
- восстановление из бэкапа и переезд между VPS — нужен второй одноразовый стенд;
- сожительство с goTelegram / goVLESS / goWARP на одной машине;
- реальное срабатывание таймеров и переживание перезагрузки хоста;
- совместимость образа 3.1 с конфигами линеек 2.0 и 1.x;
- поведение под DPI-блокировкой — только на настоящем канале.

Всё это — [STAND.md](STAND.md).
