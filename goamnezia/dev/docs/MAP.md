# goAmnezia pro — карта проекта

Состояние на 28.09.2026: 0.5.0 — новый дизайн панели, мини-аппа, бота и страниц подключения — выпущена в `dev`,
`GOAMNEZIA_VERSION` в `lib/common.sh` — `0.5.0`; к `main` идёт ветка `release/0.5.1` (подготовка `main` и исправления
по критику-новичку, NC-01…24 в трекере). Одна функция живёт в модуле ядра, а видна в четырёх местах: SSH-меню,
Telegram-бот, веб-панель (и мини-апп), ИИ-агенты (MCP). Карта и код расходятся — прав код; карту поправьте в том же
коммите.

## Как пользоваться картой

- **Ищете функцию** — §3 (где она в SSH, боте, панели и какое действие моста за ней). Экраны целиком — §4–6.
- **Меняете поведение** — чек-лист §1. Действия моста, уровни MCP и кто их зовёт — приложение; оно сгенерировано из
  `lib/actions.json` и кода интерфейсов, после правки каталога его перегенерируют, а не правят руками.
- **Спорный случай** — §7 (правила владельца) и §8 (открытое, со ссылками на [FINDINGS_TRACKER.md](FINDINGS_TRACKER.md)).
- **Подробности** — документ-контракт компонента из таблицы ниже; где он отстаёт от кода — §8. `PLAN.md`,
  `docs/DEFECTS.md`, `SPRINTS.md`, `docs/archive/`, `handoff/archive/` — история, не источник правды о текущем продукте.

## 1. Чек-лист любой правки

1. **Модуль** `lib/*.sh` — логика. SSH зовёт функцию модуля напрямую, бот, панель и MCP — мост
   `install.sh --action=<имя> --json`; интерфейсы логику не дублируют.
2. **Мост** — ветка `case` в `_action_dispatch_locked` (`install.sh`), если меняются параметры или ответ. Метки веток
   сверяет с каталогом `tests/check_actions.py`.
3. **`lib/actions.json`** — параметры и типы, `readonly` / `destructive` / `secret`, `mcp` (имя инструмента или `null`),
   описание ru и en. Из него собираются инструменты MCP и их уровни, по нему панель проверяет параметры
   (`validate_params`), `destructive` требует `confirm` в панели и MCP. После правки — перегенерировать приложение.
4. **SSH-меню** — экран в `install.sh` (§4). **Бот** — `goamnezia-bot/bot.py` (экран, маршрут, ввод текстом — §5),
   тексты `goamnezia-bot/lang/ru.json` + `en.json` с одинаковыми ключами (`check_i18n_bot.py`).
5. **Панель** — `admin-web/static/app.js` (словари `I18N` RU/EN в начале файла, разделы `NAV`, вкладки настроек
   `SG_TABS`), `index.html`, `styles.css`; новые поля — в `admin-web/server.py` белым списком (`*_payload`). Вид —
   только по `handoff/iteration3`. Слой входа не трогать (кроме правки В4).
6. **MCP** — `goamnezia-mcp/AGENT_GUIDE.md`, если меняются поля ответа или смысл вердикта.
7. **Словари SSH** — `lib/lang/ru.d/*.sh` и `en.d/*.sh`: одинаковые ключи и число `%s` (`tests/check_i18n_ssh.py`).
   Видимый текст — только `t` / `tf` с буквальным ключом: `t "$var"` проверка паритета не видит, выбор ключа — через
   `case`. Строки с `\"` правьте целиком. `2>/dev/null` — ДО перенаправления в файл (`{ …; } 2>/dev/null >"$f"`),
   страж — в `tests/test_actions_dryrun.sh`.
8. **Тесты** — при правке точечные; перед слиянием `BASH5=/opt/homebrew/bin/bash bash tests/run_static.sh` целиком
   зелёный. **Документы** — контракт компонента (таблица выше), эта карта, `DOCS_HUMAN.md` для людей.
9. **Выпуск** — `GOAMNEZIA_VERSION` в `lib/common.sh`; «что нового» — `upd_l1…upd_l12` (до двенадцати) в `lib/lang/*/menu.sh` и
   `DOCS_HUMAN.md`; новые файлы — в список `bootstrap.sh` (`tests/check_bootstrap_files.py`). Ветки две: `main` —
   стабильная, её ставит однострочник по умолчанию; `dev` — экспериментальная (`GOAMNEZIA_BRANCH=dev`). Пуш в ветку —
   выпуск людям этой ветки.
10. **Живая проверка** — `tests/live/acceptance.py`: настоящий клиент AmneziaWG с другой машины (`tests/live/README.md`).

## 2. Устройство

```
 человек по SSH ─► install.sh (SSH-меню, мастер) ──────────────┐
                                                               ▼
 Telegram ─────────► goamnezia-bot/bot.py ─┐           lib/*.sh (модули)
 браузер, мини-апп ─► admin-web/server.py ─┼─► мост install.sh --action=<имя> --json ─┘
 ИИ-агент ────────► goamnezia-mcp/server.py┘     (запись — под одним замком)
 таймеры systemd ─► мост (*-tick) · страница /p-… ─► pages_server.py ─► мост (user-key)
```

- **Одно ядро, четыре интерфейса.** Бот, панель и MCP знают только мост и права проверяют сами: бот — список админов,
  владелец, фразы подтверждения; панель — вход и `confirm`; MCP — уровень доступа read / write / admin. Мост доверяет
  вызывающему. Ответ моста — последняя строка stdout `{"status":"success"|"error","message","code",…}`.
- **Мост** (`install.sh`: `action_dispatch` → `_action_dispatch_locked`): чтение (`readonly`) — без замка, запись — под
  `flock` на `/run/goamnezia/config.lock` (ждёт 30 с, иначе `lock_timeout`). Язык слов ответа — на один вызов:
  `GOAMNEZIA_CALL_LANG=ru|en` (L-24; бот ставит язык человека, панель — заголовка `X-GoAmnezia-Lang`, MCP не ставит;
  `status.lang` — всегда язык установки). Кто позвал — `GOAMNEZIA_CALLER` / `GOAMNEZIA_WHO` (журнал действий).
- **Состояние сервера** (`/opt/goamnezia`, `GOAMNEZIA_DIR`): `config.json` (режим, домен, профили, порты, панель,
  `client_isolation`, `server_ip_change`), `users.json` (люди и пиры — единственный источник правды), `agents.json`,
  `stats.json` (сутки и 192 часа — `hours`), `state/` (копии внутренностей контейнеров, `edge_ips.csv`,
  `edge_alerts.json`, `dns.cache`, `apk_mirror`), `pages/`, `mirror/`, `backups/`, `import-snapshots/`, `tls/`,
  `appearance.json` (вид панели), `.language`, `.install-source`. В `/run/goamnezia` — замок, очередь уведомлений бота
  `notify/`, раздачи `share/` (после перезагрузки их нет). Службы — `/opt/goamnezia-{bot,admin,mcp}`.
- **Контейнеры и линии**: `amnezia-awg3` (3.1), `amnezia-awg2` (2.0; ставится всегда, его видит официальное приложение),
  `amnezia-awg1` (1.0/1.5); имена не менять. Линия профиля — `status.profiles[].line`: у подхваченного контейнера
  приложения Amnezia она может не совпадать с id, поэтому бот и панель пишут линию («AmneziaWG 3.1»), а id (`awg3`) —
  только во фразах подтверждения и именах контейнеров. Изоляция клиентов — `lib/amnezia.sh`: `ga_amn_isolation_on`,
  `ga_amn_isolation_apply` (ключ `client_isolation`).
- **Службы и порты**: `goamnezia-admin` (панель, `127.0.0.1:1985`), `goamnezia-bot`, `goamnezia-mcp-http`
  (`127.0.0.1:1986`, выключена до `mcp-http-on`), `goamnezia-pages` (`127.0.0.1:1987`); временная ссылка — одноразовый
  `share_server.py` на случайном порту TLS. nginx в режимах с сайтом: сайт, панель `/app-<86 знаков>/`, страницы
  `/p-<43>`, MCP `/a-<43>/`; в Lite MCP — свой TLS-порт (`mcp.public_port`).
- **Таймеры**: через мост (`lib/timers.sh`) — `goamnezia-quota` (5 мин), `-watch` (2 мин; сторож контейнеров и адресов,
  раз в час — переезд IP), `-stats` (10 мин), `-upstream` и `-cert` (сутки); модулем напрямую — `goamnezia-backup`,
  `-cert-renew`, `-logbudget`, `-logrotate`.

Правило портов одно на все интерфейсы (`lib/amnezia.sh: ga_amn_port_check`): порты профилей разные, UDP/443 — не больше
чем у одного. Случайный — из 1024–9999 (общеизвестные пропускаются), запасной 30000–49999 — только если низкий занят.
Pro — ровно один профиль на UDP/443, Semi-Pro — ни одного; расхождение шапка SSH, бот и мост
называют вслух (`mode_port_mismatch`), мастер его не допускает. Смена режима порт профиля не двигает.

## 4. SSH-меню

Правила экрана: управление цифрами; «0» — назад и сразу, без «Нажмите Enter» (`GA_BACK=1`); голый Enter — перерисовать;

`r<номер>`, в каталоге шаблонов `n`/`p`/`r` и поиск `/…` (библиотека «не трогать»), «r — другое» у «🎲» (T23 в трекере

## 6. Веб-панель, мини-апп, страницы (0.5.0)

персональной кнопкой меню у админов, если панель на домене.

(`typedConfirm`).

только после действия человека, до него у ключа — «Показать ключ» (SEC50-05); файл .conf и QR — с токеном из того же
ответа (SEC50-10). Без JavaScript — шапка, статус и заметка. Выключенный человек — не 404: страница (200) «Доступ
приостановлен» с причиной (выключил администратор, кончился трафик или срок) и что сделать (написать тому, кто
прислал ссылку; приложение не удалять), без ключей; файлы и QR ключей — 404. Удалённый человек (и тёзка, заведённый после удаления), истёкшая или
отозванная страница — 404 как у nginx.

**Временная ссылка** (`lib/share.sh` + одноразовый `share_server.py`): HTTPS на случайном порту, файл отдаётся сразу,
5 минут, скачивать можно несколько раз (решение В1); истёкшая, снятая или чужая — 404 как у nginx; после перезагрузки
ссылок нет.

## 7. Правила владельца (выжимка того, что чаще всего задевают правкой)

- **Порты**: случайные из 1024–9999 («старайся ставить ниже десяти тысяч», 10.09), запасные 30000–49999 — вслух.
  У каждого профиля свой порт; UDP/443 — только у одного, в Pro по умолчанию у awg2 (24.09; 2.0 — шире всего
  поддержка клиентов, включая Keenetic, 27.09; другую линию ставит выбор «Линия на UDP 443»).
- **Профили в мастере**: порядок 3.1 → 2.0 → 1.x, отмечены 3.1 и 2.0, 2.0 не снимается, у каждого строка «кому нужен».
  Про DNS мастер не спрашивает — Google.
- **Режимы** (названия 0.6.0, [MODES_047.md](MODES_047.md); внутренние id прежние): Ленивый Pro — сценарий, а не id:
  только домен, итог `pro` (UDP 443 занят — `lite_site`); Pro (`pro`) — сайт на TCP/443, VPN на UDP/443; Semi-Pro
  (`lite_site`) — домен, сайт-заглушка и панель на TCP/443 с настоящим сертификатом, VPN на своих портах; Lite (`lite`) —
  только VPN.
  Самоподписанный — только запасной путь; Let's Encrypt — на домен один раз, повторы — `GOAMNEZIA_LE_STAGING=1`.
- **Меню SSH**: только цифры (исключения — §4); «0 — назад» везде; Enter продолжает; легенда над вводом; без голого
  слова «Endpoint» в подписях; разрушительное — в конце и с подтверждением.
- **Адрес в ключах** по умолчанию: домен только в Pro, иначе IP (17.09); домен за прокси Cloudflare — IP (Ленивый Pro).
- **Панель** мастер ставит в любом режиме (NC-13, 28.09): без домена — только для SSH-туннеля, вход без пароля; на
  домене с настоящим сертификатом включается сама (17.09). Полный секретный адрес панели показывается открыто (В3,
  26.09), но только пунктом «Панель на домене» и в ответе на включение — в шапках его нет (NC-15).
- **Бот**: один токен на сервер; владелец — `OWNER_ID`; разрушительное — фразой «ГЛАГОЛ цель», в том числе
  «DELETE имя» (В2, 26.09); секретные адреса — отдельным сообщением.
- **Агенты**: у каждого свой ключ, отзыв сразу; доступами управляют SSH, бот и панель, не MCP; умолчание — `read`.
- **Временная ссылка** — как в продукте: 5 минут, многоразовая, файл сразу, на истёкшую — 404 (В1, 26.09).
- **Вид** — ТОЧНО как макет `handoff/iteration3`: анимации, иконки, компоненты, отступы (26.09); ни одного внешнего
  запроса, касание ≥ 44 px, поля 16 px, RU/EN, тёмная тема (`handoff/README.md`).
- **Не трогать**: вендоренный upstream Amnezia, логику библиотеки шаблонов, слой входа панели (кроме В4), кодек `vpn://`.

Решения 27.09.2026:
- **Изоляция клиентов включена по умолчанию** (SEC-NET-1): клиенты одного профиля не видят друг друга — и в своих, и в
  подхваченных контейнерах. Снять — только `client_isolation=false` в `config.json`; переключатель в интерфейсах —
  будущая функция (IDEA-NET-1, заморожено).
- **Администраторов бота назначает только владелец** (L-25): `/invite` и подсказка в списке админов.
- **Имя для людей — «goAmnezia pro»** во всех текстах (M6); идентификаторы, пути, репозиторий, имена служб — прежние.
- **Вход в панель через SSH-туннель — без пароля** (SEC46-04).
- **Заморозка новых функций**: доводим начатое и шлифуем под новый дизайн. Исключение — 0.6.0: Ленивый Pro, меню из
  4 режимов и линия на UDP 443 (F-1…F-3, [MODES_047.md](MODES_047.md)); сертификат на IP (F-4) по-прежнему заморожен.
- **Выпуск**: релизы идут в `dev` (экспериментальная ветка, пуш = выпуск её людям; пушить можно после зелёных ворот);
  `main` — стабильная, её ставит однострочник по умолчанию; в неё — только после внедрения редизайна (M1…M7 в трекере).
- **Перед `main`**: только критик-новичок на выпущенной 0.5.0 (путь человека: однострочник → ключ → телефон → ссылка
  другу → бот и панель) и эксплуатационные проверки в `tests/live` (перезагрузка, полный диск, ротация журналов,
  продление сертификата, откат обновления). Дельное — в работу, придирки — отклонять с короткой причиной.
