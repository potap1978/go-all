# goAmnezia pro — веб-панель

Третий интерфейс к тому же ядру, что SSH-меню `goamnezia` и Telegram-бот. Панель
**ничего не пишет сама**: каждая мутация — вызов моста
`install.sh --action=<имя> --json --k=v` под общим замком `/run/goamnezia/config.lock`
(docs/CONTRACT.md §0 п.3–4, §6). Напрямую читается только `config.json` (без
секретов), ключи пользователей — только через действие `user-key`.

Слой входа, сессий, лимитов кода и защиты от DNS-rebinding перенесён из goTelegram
Pro (`admin-web/server.py`, AUDIT.md §7); неймспейс свой, и к нему добавлен второй
равноправный вход — логин с паролем (решение владельца от 10.09.2026). Контракт
установки и интеграции — [docs/PANEL.md](../docs/PANEL.md).

## Файлы

| Файл | Что |
|---|---|
| `server.py` | сервер на stdlib (`ThreadingHTTPServer`), 127.0.0.1:1985: вход и сессии, мост к ядру, API страниц, статика |
| `static/index.html`, `static/app.js`, `static/styles.css` | фронтенд без сборки, фреймворков и CDN; RU/EN словари в `app.js`, `data-i18n` в HTML; светлая/тёмная тема — по выбору человека, а без выбора системная (`prefers-color-scheme`), теми же переменными живут окно входа поверх панели и серверная страница входа |
| `install_admin.sh` | автономный установщик: копия в `/opt/goamnezia-admin/` (0700), токен `token` (0600, `openssl rand -hex 32`), логин и пароль `password.json` (0600, на диске только хеш), юнит `goamnezia-admin.service` от root с `Restart=always`; `--auto`, `--lang=ru|en`, `--port=N`, `--login=NAME`, `--reset-password` |

Зависимости: Python ≥ 3.8 (только stdlib), `jq` и ядро goAmnezia у моста. Ни pip, ни venv.

## Как войти

Мастер первой установки ставит панель в любом режиме, без вопроса: служба слушает только
`127.0.0.1:1985`, без домена её открывают через SSH-туннель, а в режимах с сайтом на настоящем
сертификате — ещё и на домене. На сервере, поставленном без домена версией 0.5.0 и раньше, панели нет,
пока её не поставить: SSH-меню «Настройки → Веб-панель, админы бота, ИИ-агенты → Панель и мини-апп →
Установить / обновить панель» (обновление goAmnezia её само не ставит).

Через туннель ни кода, ни пароля не нужно. С домена входов два равноправных: код в Telegram — главный,
когда бот настроен; логин и пароль — единственный, когда бота нет, и запасной, когда есть.

| Способ | Чем доказывает | Когда доступен |
|---|---|---|
| SSH-туннель `ssh -L 1985:127.0.0.1:1985 root@SERVER` → `http://127.0.0.1:1985/` | входом по SSH; ни кода, ни пароля | в любом режиме |
| **Код из Telegram-бота** на странице входа | владением аккаунтом админа: 6 цифр, 5 минут, одноразовый, 5 попыток | когда у бота заданы `BOT_TOKEN` и `ALLOWED_IDS` |
| **Логин и пароль** на странице входа | знанием пароля, выданного установщиком | с домена; пароль заводится при любой установке этой версии |
| Мини-апп в Telegram (кнопка «Панель» в боте) | подпись `initData` (HMAC `WebAppData`), только админы бота | режимы с сайтом, панель на домене |
| Токен `?token=…` из `/opt/goamnezia-admin/token` | root-only файл | аварийно, через туннель на другое имя; поля ввода нет |

Когда бота нет, страница входа показывает **только** логин и пароль — про код на ней
не сказано ни слова. Логин и пароль печатает установщик **один раз**; на диске
(`password.json`, 0600) лежит соль и вывод `scrypt` — самого пароля нет нигде. Пароль нужен только
для входа с домена, поэтому мастер, ставящий панель без домена, его не показывает (в `config.json` —
`panel.password_pending`): меню выдаст пароль один раз, когда панель впервые выйдет на домен (смена
режима, выпуск сертификата, смена домена). Отметку снимают и перевыпуск пароля, и удаление панели.

Сессия — 15 минут, потом минута на продление кодом; данные в это окно не отдаются.
Продлевают только кодом: без бота панель не показывает баннер продления, а сразу
предлагает войти заново паролем. Лимиты на код раздельные: публичный вход 5/час
**на адрес** (посторонний не выжигает квоту и код администратора), туннель 30/час,
продление 12/час, кулдаун 30 с, 5 попыток на код; на весь интернет вместе после 20 кодов
в час адресу — только первый код часа, сверх 60 — никому; код принимается только с того адреса (или из той вкладки), откуда
его просили. У пароля своя корзина: 5 попыток за 15 минут на адрес, дальше временная
блокировка; место в корзине занимается до проверки пароля, поэтому параллельные
запросы не дают лишних попыток; ответ занимает одинаковое время при верном и неверном
логине. Доверие петле выключается `GOAMNEZIA_TRUST_TUNNEL=0` (или
`panel.trust_tunnel=false` в `config.json`).

## Установка

```bash
sudo /opt/goamnezia/admin-web/install_admin.sh            # напечатает логин, пароль, туннель и путь к токену
sudo /opt/goamnezia/admin-web/install_admin.sh --auto     # для вызова из SSH-меню (пароль печатает тоже)
systemctl status goamnezia-admin && journalctl -u goamnezia-admin -f
```

Повторный запуск безопасен: файлы и юнит обновляются, существующие `token` и пароль
сохраняются. Мастер без домена зовёт тот же `--auto`, но его вывод не показывает (см. «Как войти»),
а в конце печатает команду туннеля — с адресом, по которому вы зашли, и `-p`, если SSH не на 22-м порту.

## Пароль

```bash
sudo /opt/goamnezia/admin-web/install_admin.sh --reset-password      # новый пароль в терминал
sudo /opt/goamnezia/admin-web/install_admin.sh --reset-password --login=owner
```

Перевыпуск ничего больше не трогает и не требует перезапуска службы: `password.json`
читается на каждую проверку. Из панели пароль меняется в «Настройки → Пароль панели»
(текущий + новый дважды, не короче 12 символов). Пароль не попадает ни в логи, ни в
аудит, ни в один ответ API, ни в `config.json`.

## Разделы (0.5.0)

Вид — по макетам `handoff/iteration3`; где какая функция и какое действие моста за ней — [docs/MAP.md](../docs/MAP.md)
§3 и §6.

- **Оболочка**: 8 разделов, на телефоне — нижние вкладки и «Ещё»; ⌘K — поиск людей, действий, подразделов настроек
  и разделов (действие открывает окно, а не выполняется сразу); шторка «Вид» (тема, акцент, фон, карточки, кнопки,
  скругление, меню, размер текста, подробность, движение, пресеты, экспорт CSS) хранится на сервере
  (`/api/appearance` → `/opt/goamnezia/appearance.json`); разрушительное — окно с вводом слова. Мини-апп в Telegram —
  та же панель в цветах темы Telegram.
- **Обзор** — режим, люди, трафик, версия; профили и порты; здоровье служб; «Как открыть панель»; входящий трафик
  по адресам; активность по часам; тревоги: адреса из ключей нет на машине, сменился IP сервера, итог суточной
  проверки обновлений.
- **Пользователи** — поиск, отметки, сортировка, страницы; «Добавить» — шторка с «🎲»; временные ссылки на файл;
  карточка-шторка: ключ (QR `.conf` и `vpn://`, части серии, «Скачать .conf», «Скопировать vpn://», «Текст .conf»),
  лимит, срок, выключить и включить, переименовать, профили, перевыпуск ключа, «Привязать старый ключ», свой адрес
  человека, страницы подключения, удаление вводом имени.
- **Протоколы** — карточки профилей (установка, порт и UDP/443, подсеть, MTU, параметры, перезапуск, удаление),
  «Перезапустить все профили», обновления Amnezia, импорт.
- **Трафик** — период, по часам и дням, кто больше всех, по профилям.
- **Бэкапы** — копия сейчас, ночная копия и расписание, архивы, восстановление.
- **Логи** — журналы служб, журнал действий, место под логи, «Диагностика».
- **Агенты** — транспорт MCP по HTTP, доступы карточками, выдача — окно с адресом и токеном.
- **Настройки** — вкладки: Вид · Режим и сайт (смена режима пошаговым окном, каталог шаблонов, проверка сайта,
  Alt-Svc, проверка портов 80/443) · Адреса для клиентов (DNS, адрес сервера в ключах) · Копии приложений · Вход в
  панель (панель на домене, как войти, пароль, админы бота) · Язык панели и продукта · О программе.

Пока идёт действие, в шапке раздела висит плашка с его названием, объяснением и
счётчиком: установка профиля занимает до 15 минут, и всё это время панель обязана
показывать, что она жива. Если в этот момент кнопку нажмёт второй администратор, он
получит не молчание на четверть часа, а ответ «сейчас выполняется другое действие
(*имя*) — повторите через минуту».

## Временная ссылка на файл

Кнопка «Временная ссылка» в карточке пользователя (`lib/share.sh`,
[docs/SHARE.md](../docs/SHARE.md)): одноразовый HTTPS-слушатель на случайном порту,
секретный путь, по умолчанию 5 минут. Форматы — файлом: `.conf` для AmneziaWG и ключ
приложения Amnezia; QR по ссылке не нужен — картинку панель и так показывает на месте.

Адрес **равен ключу**: панель показывает его один раз, в окне сразу после создания —
с кнопкой «скопировать», сроком жизни, датой смерти и предупреждением. В список
выданных ссылок, в тосты, в логи и в аудит секретная часть адреса не попадает: в
списке видны только id, пользователь, формат, порт, остаток времени и число скачиваний.
В режимах без домена сертификат самоподписанный — рядом с адресом показывается
отпечаток SHA-256 и предупреждение, что браузер ругнётся на соединение.

## API (кратко)

Чтение — `GET /api/…` поверх read-only действий (`status` и `traffic` кэшируются 5 с;
из нового — `/api/share`, `/api/preflight`, `/api/logs/status`), мутации —
`POST /api/action/<имя>` с JSON-параметрами: валидация по `lib/actions.json`
до вызова моста, для `destructive` действий обязателен `confirm` = значение первого
параметра, ответ `{ok, data}` либо `{ok:false, error, code}` с HTTP-статусом по коду моста
(`not_implemented` → 501, `lock_timeout` → 409, `timeout` → 504, `transport` → 502).
`lock_timeout` панель выдаёт и сама, не дождавшись своей очереди за
`GOAMNEZIA_ADMIN_LOCK_WAIT` секунд (по умолчанию 3): в ответе `busy_action` — что именно
сейчас идёт. Все POST требуют заголовок `X-GoAmnezia-Admin: 1` (предохранитель от CSRF).
Полная таблица «маршрут → действие → поля» — в [docs/PANEL.md](../docs/PANEL.md).

## Проверки

```bash
python3 -m py_compile admin-web/server.py
node --check admin-web/static/app.js
python3 -m unittest tests/test_admin_features.py tests/test_admin_http.py
/opt/homebrew/bin/bash -n admin-web/install_admin.sh && shellcheck -S warning -x admin-web/install_admin.sh
```

Тесты не трогают `/opt`: панель поднимается подпроцессом на свободном порту петли с
временным `GOAMNEZIA_DIR`, мост подменён `tests/fixtures/fake_action_admin.sh`, коды 2FA
уходят в файл `GOAMNEZIA_TFA_SINK` вместо Telegram.
