# Прототипы: единая панель, 27.09.2026

Вход — `Panel.dc.html`. Он объединяет 285 именованных состояний и показывает ровно одну оболочку. Первые четыре раздела, карточки людей и профили находятся в `Panel-core.dc.html`; настройки, вход, бэкапы, логи и агенты — в `Panel-settings.dc.html`. Старые шаблоны этих пяти разделов удалены из первой части. Исходный URL `Panel-settings.dc.html?screen=…` продолжает работать: прямое открытие переводит на общий вход с теми же параметрами.

**Это комплект файлов, а не один самодостаточный HTML.** Для просмотра нужны вся папка `iteration2`, `../support.js`, `../heroui-tokens.css`, `../ga-components.css`, `../ga-icons.js`. Копии React 18.3.1 извлечены без изменений из существующего `handoff/archive/offline/Panel.html`, сохранены в `settings-assets/` и загружаются локально. Интернет для просмотра не требуется. Автономные HTML первой итерации в `handoff/archive/offline/` не обновлялись.

Из корня репозитория:

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory handoff
```

Примеры адресов:

- `http://127.0.0.1:8768/iteration2/Panel.dc.html?screen=overview&persist=0`
- `http://127.0.0.1:8768/iteration2/Panel.dc.html?screen=settings-access&device=phone&lang=en&theme=dark&persist=0`
- `http://127.0.0.1:8768/iteration2/Panel.dc.html?screen=profiles-install-443-free&lang=en&persist=0`

Параметры `screen`, `device`, `lang`, `theme`, `density`, `preset`, `nav` доступны также через интерфейс редактора DC. Общий вход хранит переходы между разделами в истории браузера; Back восстанавливает раздел. Тема и язык сохраняются при переходах между частями, в том числе при `persist=0`. Внутренние модальные действия остаются состояниями прототипа, а не отдельными URL.

`Telegram.dc.html` использует общий `Panel` для мини-апп; параметры `view=miniapp`, `screen`, `lang`, `tgScheme` задаются через свойства DC. Доступны все состояния панели, включая новые настройки. Цвета Telegram передаются обеим частям.

## Проверки

`qa/check-panels.cjs` — DOM-проверка всех состояний в desktop/RU/light и phone 360×800/EN/dark: загрузка, ошибки JS, внешние запросы, горизонтальный выход страницы, размеры целей и русский интерфейсный текст в английских диалогах. Анимации в этой проверке отключены, чтобы измерять конечные размеры. Результаты — `qa/dom-results.json` и `qa/check-output.json`.

`qa/check-flows.cjs` — реальные клики: переходы между частями, Back, сохранение темы/языка, два EN-тоста, установка с выбранным портом, положение QR и мини-апп с тёмными Telegram-цветами. Результат — `qa/flow-results.json`.

Для запуска нужен установленный Playwright и Node.js; сервер выше должен быть запущен. `GA_DESIGN_BASE` переопределяет базовый URL.

Основной прогон — DOM и поведение макетов. Дополнительно по разрешению проверены четыре скриншота: desktop overview, мобильные настройки, карточка пользователя и настройки miniapp. Исправлены перекрывающиеся мобильные вкладки настроек (заменены select) и обрезание QR-подписи.
