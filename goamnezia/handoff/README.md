# goAmnezia Pro — редизайн интерфейса. Сообщение для ИИ-агента

Привет. Здесь дизайн-прототипы нового интерфейса goAmnezia Pro: веб-панель администратора, мини-приложение Telegram, Telegram-бот, страница подключения пользователя и страница временной ссылки. Твоя задача — перенести дизайн в продукт (`admin-web/static/`, страницы подключения, сообщения бота), сохранив поведение, тексты и систему настройки внешнего вида. Ниже всё, что нужно знать.

> **27.09.2026:** прототипы итерации 1 (`*.dc.html`, `offline/`) перенесены в `archive/`. Действующие макеты —
> `iteration3/` (основа — `iteration2/`). Правила этого файла — токены, компоненты, иконки, чек-лист — в силе.

---

## 1. Как открыть прототипы

- `archive/offline/*.html` — **автономные копии**, открываются двойным кликом без интернета. Смотри дизайн по ним. Файлы `archive/offline/heroui-tokens.css` и `archive/offline/ga-icons.js` должны лежать рядом с ними в той же папке — встроенные экраны берут стили оттуда. Не разделяй папку `archive/offline/`.
  - `archive/offline/Panel Variants.html` — холст со всеми экранами и вариантами для сравнения (начни с него).
  - `archive/offline/Panel.html`, `archive/offline/Client.html`, `archive/offline/Telegram.html` — отдельные интерактивные прототипы.
- `archive/*.dc.html` — исходники прототипов (формат Design Component). Для открытия им нужен `support.js` из корня `handoff/`, и **он подгружает React с unpkg.com** — без интернета исходники не откроются. Это касается только прототипов: сам продукт React не использует и CDN не требует.
- Исходники не нужно переносить как есть: это прототипы на инлайн-стилях. Переноси дизайн, тексты и поведение, а стили собирай на классах из `ga-components.css`.

## 3. Система внешнего вида (ключевая фича)

Владелец сам выбирает вид панели в шторке **«Вид»** (кнопка в шапке и в Настройках). Всё управляется data-атрибутами на корневом элементе `[data-hero]` плюс три инлайн-переменные:

| Атрибут | Значения | Смысл |
|---|---|---|
| `data-theme` | `light` · `dark` (+ `system` — резолвить через `prefers-color-scheme`; в мини-аппе ещё `telegram`) | тема |
| `data-tint` | `neutral` · `warm` · `cool` | оттенок фона |
| `data-density` | `min` · `balanced` · `detailed` (**по умолчанию `detailed`**) | подробность: влияет на отступы и на то, какие блоки/колонки показываются |
| `data-cards` | `shadow` · `border` · `flat` | стиль карточек (задаёт `--card-bg/--card-bd/--card-sh/--tile-bg`) |
| `data-btn` | `pill` · `round` | форма кнопок (`--r-btn`) |
| `data-fs` | `s` · `m` · `l` | размер текста (`--fs`) |
| `data-vibrant` | `true` · `false` | насыщенные soft-цвета статусов |
| `data-motion` | `on` · `off` | анимации (плюс уважать `prefers-reduced-motion`) |
| `data-device` | `desktop` · `phone` | телефон: цели 44 px, другие отступы |
| `--accent`, `--accent-foreground` | oklch | цвет акцента |
| `--radius` | 0–16 px | база скруглений: поля ×1.5, карточки ×3 |

**Акценты:** goAmnezia `oklch(0.6 0.13 222)`, Синий HeroUI `oklch(0.6204 0.195 253.83)`, Небо `oklch(0.72 0.13 228)` (текст тёмный), Лаванда `oklch(0.6 0.19 293)`, Мята `oklch(0.74 0.15 163)` (текст тёмный), Коралл `oklch(0.64 0.19 33)`, Графит (светлая `oklch(0.24 0.006 286)` / тёмная `oklch(0.95 0 0)`), Свой — `oklch(0.63 0.17 <hue>)`.

**Готовые темы:** goAmnezia, HeroUI, Лаванда, Мята, Графит, Бумага — наборы `accent + tint + radius + btn + cards` (точные значения в `presets()` в `archive/Panel.dc.html`). Тема считается выбранной, если все пять совпадают.

**«Случайная»** (кнопка с игральной костью): случайно выбирает accent (или свой hue), tint, cards, btn, radius, nav, density. **Не трогает** theme и fs.

**«Экспорт CSS»** выводит текущие переменные и атрибуты.

**Хранение:** в прототипе — `localStorage['goamnezia-appearance-v1']` (JSON: theme, accent, hue, tint, density, radius, btn, cards, nav, fs, vibrant, motion). **В продукте храни на сервере** (конфиг панели), чтобы:
- выбор переживал смену браузера;
- страница подключения и страница временной ссылки клиентов получали тему владельца (их открывают другие люди на других устройствах).

## 4. Экраны панели (`archive/Panel.dc.html`)

Навигация: Обзор, Пользователи, Протоколы, Трафик, Бэкапы, Логи, Агенты, Настройки. Меню — полное / только иконки / сверху (настройка `nav`). На телефоне — нижние вкладки: Обзор, Люди, Протоколы, «Ещё» (лист с остальными).

- **Обзор:** алерт «нужно действие» (остановлен профиль → «Перезапустить», «Логи»); KPI (люди, трафик 30 дней, профили, нагрузка-кольцо) с анимацией счёта; входящий трафик по адресам сервера; список профилей с переключателями. В «Детально» ещё: мини-график трафика, тепловая карта активности 7×24, события, службы.
- **Пользователи:** фильтр-сегмент (Все / На связи / Без доступа), поиск, «Добавить», таблица-сетка. Колонки зависят от подробности: min — пользователь, статус, трафик; balanced — + профили, срок; detailed — + адрес, рукопожатие, спарклайн 7 дней. Пагинация. На телефоне — список карточек.
- **Карточка пользователя** (правая шторка, на телефоне — лист снизу): кольцо лимита, вкладки профилей, выбор адреса сервера в ключе (с подсказкой, замолчавший адрес — красным), QR с переключателем `.conf` / `vpn://` и листанием частей (vpn:// в 3 частях), «Скачать .conf», «vpn://» (копирование с морфингом в «Скопировано»), «Временная ссылка» (показывается один раз, обратный отсчёт 10 мин), «Страница», лимит (−/+), дата доступа, «Выключить», «Удалить».
- **Протоколы:** карточки профилей выровнены по строкам через CSS subgrid (`grid-row: span 5; grid-template-rows: subgrid`) — шапка, статус (прогресс обновления / предупреждение), параметры, аккордеон «Параметры маскировки» (свёрнут по умолчанию), кнопки. Выравнивание должно сохраняться на любой ширине.
- **Трафик:** период 24 ч / 7 дн / 30 дн, итоги, столбики скачано/отдано, топ пользователей, доли профилей.
- **Бэкапы:** «Создать бэкап» (состояние «Создаём…»), «Загрузить архив», автобэкап 03:00 (переключатель), занятое место, список со «Скачать» и «Восстановить».
- **Логи:** служба (select), уровень (Все / Ошибки / Важное), поиск, «Следить», «Скопировать», просмотр с подсветкой ERR/WARN, моноширинный.
- **Агенты (MCP):** служба `goamnezia-mcp-http` вкл/выкл, «Подключить агента» (адрес показывается один раз), карточки агентов с правами, переключателем и «Отозвать».
- **Настройки:** «Внешний вид» (готовые темы, подробность, «Случайная», «Все настройки»); «Режим сервера» (радио); **«DNS в ключах»** — отдельная карточка: Cloudflare / Google / AdGuard / **Свой → два поля «Основной» и «Запасной»** с валидацией IPv4 (основной обязателен); **«Вход в панель»** — отдельная карточка: переключатели и адрес панели с копированием.
- **Вход:** сегмент «Код из бота / Пароль», поле кода из 6 ячеек (InputOTP), ошибка и успех, подсказка про SSH-туннель. Демо-код: `482913`.
- **Поиск ⌘K / Ctrl+K:** люди, действия, разделы; Enter — первый результат; Esc закрывает верхний слой.
- **Подтверждения опасных действий** — вводом слова: удалить пользователя (имя), удалить профиль (`awg1`), восстановить бэкап (`восстановить`), отозвать агента (`отозвать`). Кнопка неактивна, пока слово не совпало.
- **Тосты** справа снизу (на телефоне над нижним меню), 3,2 с.

## 5. Клиентские страницы (`archive/Client.dc.html`)

Проп `page`: `connect` · `suspended` · `share` · `share-dead`.
- **connect** — «Доступ для {имя}»: статус и лимит; шаг 1 — устройство (iPhone/iPad, Android, Android TV, Windows, macOS, Linux, Роутер) и приложение (радио-карточки с меткой «официальное/стороннее», поддержка линеек 1.5/2.0/3.1, ссылки, «Копия на этом сервере»); шаг 2 — ключ на каждый профиль с кнопками. Каталог приложений в прототипе — упрощённая копия `lib/clients.json`, в продукте бери из него.
- **suspended** — причины `traffic` · `expired` · `admin`: заголовок, объяснение, «Что сделать» по шагам. Ключи скрыты.
- **share** — временная ссылка глазами получателя: файл, кольцо обратного отсчёта (10 мин), «Скачать файл» → состояние «Скачано» (ссылка одноразовая), «Показать QR», 3 шага импорта, предупреждение не пересылать.
- **share-dead** — `reason=expired` (истекла) или `reason=used` (уже скачана).
- **ТВ** (`device=tv` на `connect`): крупные цели 76 px, фокус-обводка 4 px, QR «Удобнее с телефона».
- **RU/EN** — переключатель переводит весь текст (словарь `EN_DICT` в логике). В продукте вынеси в i18n-файлы.
- На странице нет бренда VPN в заголовках — она нейтральная (так было в исходном продукте, сохрани).

## 6. Telegram (`archive/Telegram.dc.html`)

- **Бот** (`view=bot`): главное меню (статус сервера, проблемы, кнопки), Люди (по 2 в ряд, пагинация), карточка человека (QR, файл, временная ссылка, страница, выключить, удалить), Протоколы. **Нажатие inline-кнопки редактирует то же сообщение** (editMessageText), а результаты (QR, файл, ссылка, подтверждения) приходят новыми сообщениями. Удаление: бот просит отправить имя сообщением, неверное имя ничего не удаляет, `/cancel` отменяет. Оформление сообщений в реальном Telegram клиентское — переносить нужно тексты, порядок и раскладку кнопок.
- **Мини-апп** (`view=miniapp`): Panel с пропом `tg` внутри шапки Telegram. Цвета берутся из `Telegram.WebApp.themeParams` (`bg_color`, `secondary_bg_color`, `text_color`, `hint_color`, `button_color`, `button_text_color`) — атрибут `data-tgc="on"` и переменные `--tg-*` в `heroui-tokens.css`. Тёмная/светлая определяется по яркости `bg_color`. В «Вид» появляется тема «Telegram». Подписывайся на `themeChanged`.

## 7. Правила, которые нельзя нарушать

- **Никаких внешних загрузок в продукте** (CSP панели): только локальные `heroui-tokens.css`, `ga-components.css`, иконки из `icons/`, системные шрифты (`--font`, `--mono`).
- Все цвета — только через токены. Текст статуса на soft-подложке — `*-soft-foreground`.
- Цели касания на телефоне ≥ 44 px, поля ввода на телефоне 16 px (иначе iOS зумит).
- Длинные значения (ключи, адреса, домены) — моноширинные, `overflow-wrap: anywhere`; числа — `tabular-nums`; короткие метки и чипы — `white-space: nowrap`.
- Одинаковые карточки в ряду — одинаковой высоты, секции выровнены (subgrid).
- Иконка всегда с подписью или `aria-label`; у переключателей `role="switch" aria-checked`; у сегментов `aria-pressed`/`aria-selected`; фокус — `:focus-visible` 2 px `--focus`.
- Тексты интерфейса — как в прототипах: «что случилось → что сделать», конкретные сроки и числа, без восклицаний.

## 9. Что в прототипах не настоящее

- QR-коды — псевдослучайные заглушки; генерируй настоящие из ключа.
- Все данные демонстрационные (пользователи, трафик, логи, бэкапы, агенты).
- «Загрузить архив», «Порт», «MTU», «Страница», пагинация — без логики.
- Переключатель RU/EN есть только на клиентских страницах; в панели язык задаётся отдельно.

## 10. Чек-лист приёмки

1. Все 8 разделов панели + вход + ⌘K + шторки «Вид» и карточки пользователя работают на 1440, 1024, 768, 390 и 320 px.
2. Все 6 готовых тем, «Случайная», свой оттенок, 3 подробности, 3 стиля карточек, 2 формы кнопок, 3 меню, 3 размера текста — в светлой и тёмной теме без поломок и потери контраста.
3. Выбор вида сохраняется на сервере и применяется к клиентским страницам.
4. Протоколы: карточки выровнены на любой ширине.
5. DNS «Свой»: два поля, валидация, основной обязателен.
6. Опасные действия — только через ввод слова.
7. Мини-апп берёт цвета Telegram и реагирует на смену темы.
8. В сетевой вкладке браузера — ни одного внешнего запроса.
9. Лицензии на месте.
