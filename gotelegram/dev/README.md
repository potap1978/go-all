# goTelegram Pro

Установщик и панель управления Telegram MTProxy на ядре `telemt`. Ставит на VPS
прокси, сайт-маскировку, Telegram-бота, веб-панель, сбор статистики и бэкапы.

Снаружи сервер выглядит обычным HTTPS-сайтом, а Telegram-клиенты используют тот
же домен и порт для MTProxy. Управлять можно из SSH-меню, из Telegram-бота или
из веб-панели.

## Что входит

- ядро `telemt` с fake-TLS маскировкой;
- SSH-меню `gotelegram`;
- Lite-режим без домена и Pro-режим с доменом, сайтом и Let's Encrypt;
- каталог из 33 000+ проверенных шаблонов сайта-маскировки (свободные лицензии), выбор с поиском в SSH и боте;
- Telegram-бот: ключи, QR, экспорт, статус, трафик, логи, бэкапы, анти-DPI,
  WARP-egress, публикация панели;
- веб-панель на `127.0.0.1:1984` — через SSH-туннель или с домена по секретному
  адресу, вход по коду из бота;
- анти-DPI: пресеты ядра и внешний SYN-фикс (V3/V4);
- WARP-egress: выход к дата-центрам Telegram через Cloudflare с fail-open;
- WEB-прокси (Telegram Desktop 7.1+): MTProxy внутри обычного HTTPS с вашим доменом,
  вторая ссылка на каждый ключ тем же секретом; только Pro, ядро telemt 3.5.5+;
- бюджет логов — не более 300 МБ на компонент;
- ручные и запланированные бэкапы;
- shared-443 для совместной работы с 3x-ui/Xray.

## Установка

Под `root` на Ubuntu/Debian:

```bash
export GOTELEGRAM_PAT="YOUR_READ_ONLY_GITHUB_TOKEN"; bash <(curl -sL -H "Authorization: token $GOTELEGRAM_PAT" https://raw.githubusercontent.com/anten-ka/gotelegram_pro/main/bootstrap.sh)
```

`bootstrap.sh` скачает файлы в `/opt/gotelegram`, создаст
`/usr/local/bin/gotelegram` и откроет главное меню.

## Режимы

**Lite** работает сразу, без домена: клиент подключается к `IP:443`, прокси
имитирует TLS под чужой популярный домен.

**Pro** требует домен, указывающий на VPS. Telegram-клиенты и браузеры приходят
на один и тот же `443`: Telegram-трафик забирает `telemt`, остальное он отдаёт
на локальный `nginx`, который показывает сайт-маскировку.

## Панель

Два входа, оба ведут в одну и ту же панель.

**Через SSH-туннель** — работает всегда, не зависит ни от домена, ни от бота:

```bash
ssh -L 1984:127.0.0.1:1984 root@SERVER_IP
```

Затем откройте `http://127.0.0.1:1984/`. Токен лежит в
`/opt/gotelegram-admin/token`.

**С домена, в обычном браузере** — включается в меню: `Настройки → Панель →
Панель на домене`. nginx начинает отдавать панель по неугадываемому пути на
вашем домене; вход по коду, который приходит в Telegram-бота. Этот способ
требует привязанного бота с админами — код приходит именно туда.

Сессия живёт 15 минут, затем даётся минута на продление кодом.

## Ветки

- `main` — продакшен, из неё ставится `bootstrap.sh`;
- `dev` — рабочая ветка, сюда идут все изменения;
- `rc1` — кандидат в релиз.

Изменения попадают в `dev`, и только после проверки — в `main`.

## Проверки перед пушем

```bash
bash tests/run_static.sh
```

Прогоняет структуру меню, полноту словарей в обоих языках и модульные тесты.
Отдельно, если менялся синтаксис:

```bash
bash -n bootstrap.sh install.sh lib/*.sh
python3 -m py_compile gotelegram-bot/bot.py admin-web/server.py
node --check admin-web/static/app.js
git diff --check
```

Живые стенды (нужен установленный сервер) описаны в
[tests/README.md](tests/README.md).
